# IZISONO — sources des démos vocales IA

Les cartes Explorer utilisent des références publiques de chansons IA vocales hébergées sur Pixabay. Les pages indiquent que les morceaux sont générés par IA et disponibles sous la Pixabay Content License.

- Beautiful Dreams — Pop / Vocal / AI : https://pixabay.com/music/pop-beautiful-dreams-479932/
- You and Me (AI Vocal) — Vocal / AI : https://pixabay.com/music/vocal-you-and-me-ai-vocal-485911/
- Release — Vocal / Lo-fi / Pop / AI : https://pixabay.com/music/vocal-release-471384/
- Let it Happen — Alternative Pop / Male Vocal / AI : https://pixabay.com/music/pop-let-it-happen-473569/

Les quatre fichiers WAV présents dans `assets/demos/` restent des aperçus locaux de style déjà inclus dans le projet. Les boutons « Écouter la chanson IA vocale » ouvrent la source originale afin d'éviter de redistribuer les fichiers tiers sans téléchargement/licence explicite.

Pour les chansons générées par les utilisateurs, Izisono continue d'utiliser Mureka via `MUREKA_API_KEY`.
